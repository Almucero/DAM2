Descripción detallada

Botón personalizado que cambia su color de fondo aleatoriamente al ser presionado. Hereda toda la funcionalidad estándar de un Button de WPF.

Utiliza la clase System.Random para la generación de colores RGB. El estilo visual se define en el archivo Generic.xaml.
